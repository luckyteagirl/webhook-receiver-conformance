# Agent Readiness Checklist

- [ ] Task dependencies are complete.
- [ ] Allowed, forbidden, and exclusively owned files are explicit.
- [ ] Authoritative requirements, ADRs, interfaces, schemas, and tests are cited.
- [ ] No public interface must be invented.
- [ ] Scope and non-goals are bounded.
- [ ] Error/security/edge cases are enumerated.
- [ ] Deterministic commands and expected outputs are provided.
- [ ] Completion evidence is objective.
- [ ] Parallel ownership does not overlap.
- [ ] Handoff tells the next agent what changed and what remains.
