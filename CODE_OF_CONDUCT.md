# Code of conduct

## Scope

This policy applies to project issues, pull requests, discussions, reviews, and project events.

## Required conduct

Use clear and respectful language. Give technical feedback about the work and not about the person.

Accept different experience levels and viewpoints. Correct an error without insults, threats, or repeated unwanted contact.

Do not publish private data. Do not use sexual content, harassment, discrimination, or personal attacks.

## Enforcement

Repository maintainers enforce this policy. They review available evidence and protect private details when possible.

Maintainers can edit content, remove content, lock a discussion, reject a contribution, or restrict a participant.

The response must match the severity and context of the conduct.

## Report a problem

Use GitHub's private report function for content that breaks GitHub policy.

Use the private report form on the repository Security page for a private conduct report.

Put `Conduct report` in the report title. Repository owner `@luckyteagirl` monitors the form.

Do not put private conduct evidence in a public issue.

## No retaliation

Do not retaliate against a person who makes a good-faith report or helps with a review.

A knowingly false report can break this policy.
